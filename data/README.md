# data folder

Holds all of the ArchiMED application's user data.
Its **contents are not versioned** (see `.gitignore`) — only these `README.md` files and an
empty `settings.json` are tracked, so the actual data must be copied manually onto each
machine.

```
data/
├── collections/    → register collections (scans + OCR)
├── models/         → Kraken OCR models (.mlmodel)
├── indexes/        → full-text search indexes (generated by the app)
├── tasks/          → state of the background task engine (OCR runs, index builds)
│   └── control/    → commands posted to a task owned by another machine
├── locks/          → scope locks held by a running task (multi-PC deployment)
└── settings.json   → OCR settings set from the app (created on first save)
```

`tasks/` and `locks/` are pure runtime state, created and cleaned up by the application:
never edit them by hand. See
[docs/ARCHITECTURE.md](../docs/ARCHITECTURE.md#background-tasks).
